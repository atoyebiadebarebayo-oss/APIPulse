# ⚡ APIPulse — Lightweight REST API Testing Studio

APIPulse is a fast, in-browser REST API testing studio built with pure HTML5, CSS3, and JavaScript. Designed for web developers, API engineers, and creators, it allows you to send HTTP requests, inspect pretty-printed JSON payloads, monitor response latency, and maintain request history locally.

---

## ✨ Key Features
* 🚀 **Full HTTP Method Support**: Test `GET`, `POST`, `PUT`, `DELETE`, and `PATCH` endpoints.
* ⏱ **Real-Time Latency & Status Tracking**: Display response status codes and round-trip timing in milliseconds.
* 📜 **Request History Persistence**: Saves recent endpoints locally in browser LocalStorage for one-click re-testing.
* 🎨 **JSON Header & Body Editors**: Tabbed input panels with clean placeholder structures for rapid payload setup.
* ⚡ **Zero Dependencies**: Pure Vanilla JavaScript with no heavy build tools or framework overhead.

---

## 🛠 Tech Stack
* **Frontend**: HTML5, CSS3, JavaScript (ES6+)
* **Storage**: Browser LocalStorage
* **Hosting**: Vercel / Netlify / GitHub Pages
